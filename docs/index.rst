Check Your Microphone Before Requesting Help
============================================

Many Voice Typing problems are caused by microphone settings rather than the Google service itself.

Before seeking support, verify:

* Microphone is connected correctly.
* Correct microphone is selected.
* Microphone permissions are enabled.
* Input volume is properly adjusted.
* Background noise is minimized.
* Audio drivers are updated.

Testing the microphone with another application can help determine whether the issue is related to hardware or software.

Browser Troubleshooting
=======================

Google Voice Typing requires browser permission to access your microphone.

Verify these settings:

* Microphone access is allowed.
* Correct audio input device is selected.
* Browser is updated.
* Website permissions are enabled.

Restart the browser after making any changes so the updated settings take effect.
